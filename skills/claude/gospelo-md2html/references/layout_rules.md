# ページ区切りの規則 (要約)

高さは Playwright で実測する (推定しない)。ページはコンテンツ高さの 98% まで詰める。

| ブロック | 収まらないとき |
| --- | --- |
| pagebreak (`<!-- pagebreak -->`、スライドで `--hr-break` 時の `---`) | 常に改ページ |
| h1 | 文書: 1 ページ目のみ。スライド: 表紙 |
| h2 | 文書: 「h2 + 本文 3 行」が入らなければ改ページ。スライド: 常に改ページしヘッダーへ |
| h3 / h4 | 「見出し + 本文 2 行」が入らなければ改ページ (keep-with-next) |
| paragraph | 行単位で分割。各側 2 行以上。分割できなければ丸ごと次ページ |
| list | 項目単位で分割。番号付きは続きの番号を引き継ぐ |
| table | 行単位で分割。ヘッダー行を繰り返し「(続き)」。残りに 3 行未満しか入らなければ丸ごと次ページ。表全体が 1 ページに入るなら分割しない |
| code | 15 行以下は分割しない。16 行以上は行単位、各側 3 行以上。続きに「(続き)」 |
| image / mermaid | 分割しない。左右分割では図の枠へ (1 ページ 1 枚)。単段では次ページへ |
| quote / html | 分割しない |

`build` はコンテンツ JSON のページ境界を出発点にし、はみ出した分だけを同じタイトルの続き
ページ (`id-2`, `id-3`) へ送る。前のページに詰め直すことはしない。全体を組み直すのは
`--reflow` だけ。

検証: 生成 HTML を開き、各ページの `.column-text` の使用高さを測る。はみ出しがあれば末尾
ブロック (1 ブロックだけなら表の行 / リスト項目 / コード行) を続きページへ送って再生成する。
上限 3 回、超えたら終了コード 2。
