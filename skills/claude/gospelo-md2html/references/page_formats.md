スライド (16:9, 4:3):

- 1 スライド = h2 セクション。h2 はヘッダー帯に本文 x 1.25 (`--title-scale`) で表示し、本文からは消す。
- h1 は表紙スライド。h2 より前の前文は h1 をタイトルにした 1 枚になる。
- 続きスライドはヘッダーに「(続き)」。

2 段 (横長用紙の既定、`--columns two`):

- コンテンツ領域を左右 2 段に分け、ブロックを左段の上から下へ、次に右段へと流す (N 順)。
  右段も一杯になったら同じタイトルの続きページ。
- 列数 4 以上の表、コード、`html` は幅いっぱいの帯になる。図は「段に置く」より「帯に置く」方が
  大きく描ける場合に帯になる (段の枠 = 段幅 x 段の高さ、帯の枠 = コンテンツ幅 x 高さの 0.6
  で縮小率を比べる)。
  帯の直前の見出しも帯に入る。レイアウト JSON の `overrides` で `span` (1 = 段、2 = 帯) を
  ブロック単位に指定できる。
- 左段に入らない図は、右段が空ならその先頭に置き、テキストは左段に流れ続ける。
- 帯の前とセクションの末尾では、2 段の区間が空き高さの 40% 以上あれば両段の高さを揃える
  (揃えると高くなる場合は揃えない)。
- 図は段の幅に合わせて縮小 (拡大しない)。縮小率 0.5 未満は警告。

図の枠 (`--columns split`):

- 片側に図 (image / mermaid) を 1 枚、もう片側にテキスト。図の側は既定で右 (`--figure-side`)。
- 図が無いページは単段に戻る。図が 2 枚以上なら 2 枚目以降は続きページへ。
- 図は段の幅に合わせて縮小 (拡大しない)。縮小率 0.5 未満は警告。

単段 (`--columns single`、縦長用紙の既定):

- 図は高さ上限がコンテンツ高さの 0.6 (`overrides` の `maxHeightRatio` で変更可)。

タイポグラフィ (F = 本文 px): h1 1.6F / h2 1.35F / h3 1.15F / h4 1.0F 太字、表 0.9F (スライド 0.85F)、
コード 0.85F 等幅、行間 1.6 (スライド 1.5)。
